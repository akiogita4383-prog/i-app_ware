## 1. アプリ概要

ユーザーの手持ちの洋服をクローゼットとして管理し、天気・カレンダー予定・パーソナルカラーに合わせて AI（Claude Haiku）が毎日最適なコーディネートを提案するファッションアシスタント PWA。

### 主な機能

| 機能 | 説明 |
|------|------|
| デイリーコーデ提案 | 当日初回ログイン時に天気+クローゼットを元にAIが3パターン提案 |
| クローゼット管理 | 写真スキャン or 手動入力でアイテムを登録・管理 |
| AIコーデ生成 | 登録アイテムを組み合わせてアバターに着せてプレビュー |
| カレンダー連携 | コーデをカレンダーに記録・予定管理 |
| ショッピング提案 | 手持ちに合う新アイテムをYahoo!ショッピングからAIが提案 |
| パーソナルカラー | 好みの色を設定し、ショッピング検索に反映 |
| コーデ履歴 | 過去のコーデを一覧・カレンダー表示。着用評価（星1〜3）対応 |

## 3. データ構造

### ClothingItem（洋服アイテム）

```
id, userId, category, name, color, material, silhouette,
tags[], imageUrl, thumbnailUrl, aiConfidence, wornCount,
lastWornAt, memo, createdAt, updatedAt
```

**category 値:** tops / bottoms / outer / shoes / accessories / other

### OutfitHistory（コーデ履歴）

```
id, userId, date, context, itemIds[], itemReasons{},
aiTitle, aiTips, aiTags[], status, rating, ratingNote,
wornAt, createdAt, items[]
```

**status 値:** draft（下書き） / adopted（着用） / skipped（スキップ）

### Event（カレンダー予定）

```
id, userId, title, startAt, endAt
```

### 5-1. デイリー画面（初回表示）

**URL:** `/daily`  
**表示タイミング:** ログイン済みユーザーがホームにアクセスした際、当日まだ未表示の場合に自動リダイレクト  
**管理方法:** `localStorage["ware-daily-screen"]` に当日 `yyyy-MM-dd` を保存。次回以降の当日アクセスでは即座にホームへリダイレクト。

```
┌─────────────────────────────────┐
│  Good morning!♡           🔔   │  ← 時間帯別挨拶（pink italic）
│  おはようございます、もえさん🌸     │
│  今日も素敵な1日になりますように✨  │
├──────────────┬──────────────────┤
│              │ 📅 今日の予定      │
│  ✦おすすめ    │ 4月25日（金）       │
│   コーデ      │ 10:00 ● チームMTG │
│              │ 13:00 ● ランチ    │
│  [アイテム     │ 15:00 ● 打合せ    │
│   サムネイル   ├──────────────────┤
│   2×2グリッド] │ ☁️ 今日の天気 東京  │
│              │ ☀️ 25℃ 晴れ       │
│  ────────    │ 最高25℃ 最低12℃   │
│  タイトル      ├──────────────────┤
│  理由テキスト  │ ♡ ひとこと         │
│              │ 今日のコーデで気分   │
│  ● ● ●      │ 上げていこう✨       │
├──────────────┴──────────────────┤
│  ████ このコーデでスタート ›  ████  │  ← ピンクgradient
│       他のコーデも見る             │  ← outline
└─────────────────────────────────┘
```

**左カード（おすすめコーデ）**
- AI から返却された推奨コーデ3パターンをカルーセル表示（ドットで切替）
- アイテムサムネイルを最大4枚 2×2グリッドで表示
- コーデタイトル・推奨理由を下部に表示

**右上（今日の予定）**
- `/api/events?from=today&to=today` で当日予定を取得
- 予定なし時は「予定なし」と表示
- 最大4件表示（overflow は非表示）

**右中（今日の天気）**
- Open-Meteo API（東京固定）から気温・天気コードを取得
- 天気アイコン・現在気温・最高/最低気温を表示

**右下（ひとこと）**
- `/api/daily/message` から AI 生成メッセージを取得
- 天気・気温・曜日をもとに Claude Haiku が40文字以内で生成

**ボタン**

| ボタン | アクション |
|--------|-----------|
| このコーデでスタート | `POST /api/outfit/draft` で当日コーデを保存 → ホームへ遷移 |
| 他のコーデも見る | localStorage に見済みフラグを立て → ホームへ遷移 |

**AIコーデ生成エリア**

| 操作 | 動作 |
|------|------|
| アイテムをタップ | アバターに着せる（レイヤー表示）。ドラッグで位置調整可能 |
| 「AIでコーデを提案する」 | `/api/outfit/recommend` で推奨コーデを自動選択・適用 |
| 「このコーデでスタート」 | `POST /api/outfit/draft` で今日（またはURLの日付）のコーデを保存 |

**アバター選択**  
設定画面で選択したアバター画像（4種）を表示。  
服レイヤーはカテゴリ別 z-index で制御（アウター > トップス > ボトムス > シューズ）。

**アイテム追加モーダル**

| 追加方法 | 動作 |
|----------|------|
| 写真スキャン | 画像アップロード → `/api/items/analyze` でAI解析（カテゴリ・色・素材などを自動判定）→ 確認・修正後 `/api/items/confirm` で保存 |
| 手動追加 | フォームで名前・カテゴリ・色・素材・タグ等を入力して保存 |

**持っているアイテム（OwnedItemSelector）**
- クローゼットからアイテムを横スクロールで選択
- 選択したアイテムはショッピング提案のコンテキストとして使用

**探したいカテゴリタブ**
- 5カテゴリ: トップス / ボトムス / ワンピース / アウター / シューズ
- 持っているアイテムと同じカテゴリは選択不可（「所持済」バッジを表示）

**おすすめ商品カルーセル（3枚横スクロール）**

各カードは1つの「検索キーワード」に対応：

| 要素 | 内容 |
|------|------|
| ヘッダー | 「探しているアイテム」ラベル + AI生成キーワード（例: 「フレアスカート ベージュ シフォン」） |
| 商品リスト | 最大4件を縦リスト表示。左のラジオボタンで1件を選択 |
| 購入ボタン | 商品ごとに配置。Yahoo!ショッピングの商品ページを別タブで開く |
| 選択中表示 | 「選択中: 〇〇〇」を生成ボタン上部に表示 |
| AIで生成 | 選択商品 + 持っているアイテムを組み合わせてコーデ画像をAI生成 |

**AI生成フロー**
1. 選択商品と手持ちアイテムを `/api/coordinate/generate` へ送信
2. 生成されたコーデ画像をモーダルで表示
3. 「Likeに保存」でローカルストレージへ画像を保存

**Yahoo! ショッピング検索ロジック**
1. 手持ちアイテム・探したいカテゴリ・パーソナルカラーをもとに Claude Haiku が3つの検索キーワードを生成
2. 各キーワードで Yahoo! ショッピング API V3 に検索（カテゴリジャンルIDでレディース絞り込み）
3. 各キーワードの結果を独立したグループとして返却

**洋服カテゴリー分類**

| カテゴリ | サブカテゴリ（抜粋） |
|----------|------|
| トップス | Tシャツ / シャツ / ブラウス / ニット / カーディガン / スウェット / パーカー / ベスト / キャミソール |
| ボトムス | スカート（タイト/フレア/プリーツ/マーメイド） / パンツ（ストレート/ワイド/テーパード/スキニー/フレア） |
| ワンピース | Aライン / フレア / マーメイド / シャツ / タイト |
| アウター | ジャケット / コート / ブルゾン / ジレ |
| シューズ | パンプス / ローファー / スニーカー / サンダル / ブーツ |

**色オプション（13種）:** ホワイト・ブラック・グレー・ベージュ・ブラウン・ネイビー・ブルー・ピンク・レッド・グリーン・イエロー・パープル・その他

**素材オプション（10種）:** ニット・デニム・レザー・レース・シフォン・サテン・ツイード・コーデュロイ・スウェット・その他

## 7. AI 連携仕様

すべて Claude Haiku (`claude-haiku-4-5-20251001`) を使用。

### コーデ提案（/api/outfit/recommend）

**入力:** 天気コード・気温（現在/最高/最低）・降水確率・クローゼット全アイテム  
**出力:** 3パターンの `{ title, reason, itemIds[], tags[] }`  
**制約:** 実在するアイテムIDのみ使用・3パターンは異なるスタイル  

### ショッピングキーワード生成（/api/shopping/search）

**入力:** 検索カテゴリ・手持ちアイテム・パーソナルカラー  
**出力:** 3つの検索キーワード（サブカテゴリ名＋色＋素材の組み合わせ）  
**プロンプト:** 新カテゴリー分類表（taxonomy）を付与して精度を向上  

### 今日のひとこと（/api/daily/message）

**入力:** 天気状態・気温・曜日  
**出力:** 40文字以内の前向きなメッセージ（絵文字1〜2個）  
**失敗時:** ランダムフォールバックメッセージ4種から返却  

### 写真AI解析（/api/items/analyze）

**入力:** 洋服の写真（base64）  
**出力:** `{ category, name, color, material, silhouette, tags[], confidence }`  

### コーデ画像生成（/api/coordinate/generate）

**入力:** アイテム名・カテゴリ・画像URLのリスト  
**出力:** Base64エンコードの PNG 画像

## 9. 認証フロー

```
┌──────────┐         ┌─────────────┐        ┌────────────┐
│  クライアント │         │  API Routes  │        │  Database  │
└──────────┘         └─────────────┘        └────────────┘
     │                      │                      │
     │  POST /api/auth/login │                      │
     │─────────────────────>│                      │
     │                      │  SELECT user         │
     │                      │─────────────────────>│
     │                      │<─────────────────────│
     │                      │  bcrypt.compare()    │
     │  { accessToken,      │                      │
     │    refreshToken,     │                      │
     │    user }            │                      │
     │<─────────────────────│                      │
     │                      │                      │
     │  API Request         │                      │
     │  Authorization: Bearer {token}               │
     │─────────────────────>│                      │
     │                      │  jwt.verify()        │
     │                      │  requireAuth(req)    │
     │  Response            │                      │
     │<─────────────────────│                      │
```

- accessToken: JWT（有効期限あり）
- refreshToken: DB に保存、`POST /api/auth/refresh` で新 accessToken を発行
- ログアウト時: `clearAuth()` で Zustand ストアをクリア
